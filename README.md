## 🚀 Overview

A high-performance personal portfolio built with modern frontend engineering principles. Features custom animations, smooth kinetic scrolling, responsive layout architecture, and high-speed delivery.

### Key Highlights
- **Typography & Aesthetics:** Curated editorial styling with Bebas Neue, Antonio, Newsreader, and JetBrains Mono.
- **Kinetic Smooth Scroll:** Integrated with [Lenis](https://github.com/darkroomengineering/lenis) and [GSAP](https://gsap.com/).
- **Micro-Interactions:** Smooth interactive UI animations powered by [Motion](https://motion.dev/).
- **Optimized Assets:** Granular code-splitting, fast asset pipelines, and responsive media handling.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 8 (Rolldown engine)
- **Styling:** Tailwind CSS v4
- **Animations:** Motion (Framer Motion) + GSAP ScrollTrigger
- **Scroll Engine:** Lenis Smooth Scroll
- **Icons:** Lucide React

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Imama1076/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Build production bundle with optimized code splitting
npm run build

# Preview production build locally
npm run preview
```
